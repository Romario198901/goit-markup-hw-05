# GoIt Markup Homework 05

Simple static markup project for the GoIt frontend course.

## Description

This repository contains the static markup, styles, and a small JavaScript modal used for the homework assignment.

## Project structure

- index.html — main page
- css/styles.css — styles
- js/modal.js — modal behavior
- images/ — assets

## Usage

Open `index.html` in your browser, or serve the folder locally:

```bash
# using Python 3
python -m http.server 8000

# then open http://localhost:8000
```

## Development

- Edit HTML/CSS/JS files in your editor
- Refresh the browser to see changes
